# Signal spec: Volatility regime

The volatility regime signal tells users whether a coin is currently calm, normal, or turbulent, so beginners can size positions and expectations before they buy. For each supported coin, compute daily log returns from the last 90 days of daily closes (CoinGecko `market_chart`, `days=90`), then the 14-day realized volatility (standard deviation of the last 14 daily returns, annualized by √365) and compare it to the median of the rolling 14-day volatility over the full 90 days. If current volatility is below 0.75× the median the regime is **Calm** (`neutral`, reason: "Price swings are smaller than usual"); above 1.5× the median it is **Turbulent** (`bearish`, reason: "Price swings are much larger than usual — expect sharp moves"); otherwise it is **Normal** (`neutral`). It ships as a pure `volatilityRegimeSignal(candles)` function in `src/lib/signals.ts` returning the standard `{ direction, label, reason }` shape, is added to `/api/signals` with the same 15-minute cache, and appears as a third badge on each homepage coin card; coins with fewer than 30 days of data return `null` and show no badge.
